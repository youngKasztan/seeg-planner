# Headset and Unity

Everything about the headset app: hardware and software, setting up the Unity project, how the patient is loaded, testing on a laptop, running on the Meta Quest 3, the controls, aligning the hologram with the head and keeping it there when the head moves (QR codes), and troubleshooting.

The headset only **displays** what the desktop planner exported; it does not plan.
