# Data sources and safety

## Test data and tools

| Resource | Use | Link |
|---|---|---|
| IXI dataset | test subject IXI057 (T1, TOF-MRA, DTI) | https://brain-development.org/ixi-dataset/ |
| expert vessel segmentations for IXI | artery validation | https://zenodo.org/records/17393202 |
| FastSurfer weights | segmentation | https://zenodo.org/records/10390573 |
| VENAT venous atlas (Huck et al. 2019) | veins prior | https://figshare.com/articles/dataset/7205960 |
| MNI152 template | atlas registration | bundled with nilearn |

## Safety and regulation

Research prototype, **not for clinical use**. Clinical use would require medical-device certification (EU MDR). Every exported plan carries the note "automatic proposal, must be reviewed by the surgical team". Priors and estimates are always labelled as such. Patient data is never stored in the repository.
