# Updating these docs

## Structure

- `docs/README.md` - home page with all categories;
- `docs/NN-category/README.md` - category page with its subpages;
- one `.md` file per topic.

The breadcrumb at the top, the "previous / up / next" bar at the bottom and the page lists on the home and category pages are generated by

```
python tools/docs_nav.py
```

The reading order, titles and one-line descriptions are defined in the `PAGES` list at the top of that script. To add a page: write the `.md` file (first line `# Title`), add it to `PAGES`, run the script. The generated parts sit between `<!-- nav:... -->` comments and are replaced on every run, so the rest of a page can be edited freely.

## Conventions

- English, Markdown; formulas in GitHub math (inline math between dollar-backtick pairs, display math in `math` code blocks);
- every page starts with an **In short** box; reasons in **Why** boxes;
- numbers are the defaults of `robot.toml`; when the code changes, update the page of that step.
